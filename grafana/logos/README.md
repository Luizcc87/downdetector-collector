# Logos para o Painel Downdetector

Coloque um SVG por serviço aqui, com o nome igual ao campo `logo` do `services.yaml`.

Exemplo:
- `cloudflare.svg`
- `itau.svg`
- `nubank.svg`

Durante o deploy, este diretório é copiado para `/var/lib/grafana/plugins/static/downdetector/logos/`, ficando acessível em `https://<grafana>/public/plugins/downdetector/logos/<file>.svg`.

Para uso interno apenas. Não republique externamente.
